# Bundled icons

Symbolic icons copied unmodified from the
[Adwaita icon theme](https://gitlab.gnome.org/GNOME/adwaita-icon-theme)
(version 50), so the window shows them on every icon theme, not only Adwaita.
Adwaita's icons are dual-licensed under the LGPL v3 and CC BY-SA 3.0; see
`COPYING` in that repository.

They're compiled into the `usbc` binary by `build.rs` via `usbc.gresource.xml`.
